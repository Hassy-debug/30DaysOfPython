## Libraries used
`requests`, `beautifulsoup4`, `pandas`, `numpy`, `matplotlib`, `scipy`, `seaborn`

Install them with:
```
pip install requests beautifulsoup4 pandas numpy matplotlib scipy seaborn
```

## How to run
1. Clone or download this repository.
2. Open a day's folder in VS Code.
3. Run a file with `python filename.py`.

Some files need data files from the course (for example `countries_data.json` or `hacker_news.csv`), which are included in the folders that use them.

## Note on API keys
The cats API exercise in `day_15` needs a free API key from [thecatapi.com](https://thecatapi.com). Replace `PASTE_YOUR_KEY_HERE` with your own key to run it.
